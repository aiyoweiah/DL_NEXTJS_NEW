## 01 · DODO 是什么 / 不是什么

**一句话定位：**
DODO Learning 是一套真人、在线、一对一的英语语言艺术课程，通过 LCS 体系（语言循环体系）在精熟层面培养英语——涵盖 L 文学精读与 C 系统写作之下完整语言教育的五大板块，外加书本与 App 都给不了的真人"表达（Speaking）"板块——每一节课都有一位具备资质的导师（Navigator）。

**规范定位陈述**（唯一组装完成的定位——用作 /about、/methodology、销售的战略主轴）：
> 面向希望把孩子的英语打磨到学术与职业生活所要求的精熟层级的家庭，**DODO 是一套真人、一对一的英语语言艺术课程**，带来可量化的阅读与写作精熟——每个16周周期提升约一个年级——**不同于**补习、App 或 ESL，也不同于家长买得到却教不了的天才英语教材，**因为** DODO 由专家导师直播交付这一传统，并加入书本与 App 都给不了的口头辩护"表达"板块。

| DODO 不是 | DODO 是 |
|---|---|
| 补习中心 | 认知发展课程 |
| ESL 课程 | 英语语言艺术课程 |
| 补差服务 | 塑造优势的课程 |
| 应试机构 | 学生"顺带"通过考试的课程 |
| 作业辅导平台 | 导师带领的结构化学习历程 |

**区隔 DODO 的那一句话：**
> *"我们在精熟层面培养英语思维者。"*

**承诺（每一个转化页 hero 都要用）：**
每个 16 周周期提升约一个年级的阅读水平（§11 规范）。具体的 Lexile 增量。具体的 6+1 特质进步。第 0 · 8 · 16 周，数字都看得见。*（D99 再裁定 2026-09-05：规范恢复为每周期速率，取代 v6 的两周期更正。速率主张只以 §11 为源。）*

## 01b · 异议、AI 之问与反向画像（2026-08-26 新增）

> **AI 反驳的规范出处。** 完整的"为什么不直接用 ChatGPT？"答复以此处为准。其他位置——真理 2（§02）、/compare 话术表（§01）、§04a——一律*引用*它，不要复述整段论证。

**异议 → 回应**（真正的成交障碍；回应保持肯定、数字优先）：

| 异议 | 回应 |
|---|---|
| "太贵了。" | "你买的不是课时，而是一套可量化的认知架构。每个周期约一个年级，第 0/8/16 周都看得见。续费前，成果已经写在纸上。" |
| "孩子在校英语已经拿 A。" | "校内英语奖励流利度。我们构建 A 尚未考察的分析性阅读与学术写作——大学与领导力真正要求的层级。" |
| "线上一对一比得上线下吗？" | "对这件事更好：一位导师、孩子全部的注意力、每节课皆可量化。地理不再重要，关系依旧。" |
| "16 周是很大的承诺。" | "一个周期就是一段可量化的弧——第 0、8、16 周。你在再次决定前就看见 Lexile 移动。先从一个周期开始。" |
| **"为什么不直接用 ChatGPT？"**（AI 之问） | "AI 是孩子一辈子都会用的工具。我们培养用好它的判断力——AI 无法*替*孩子完成的阅读、推理与写作。它回答问题；导师教孩子该问哪个问题。" |

**要化解的转换焦虑**（JTBD 的"焦虑"力——先点名，再回应）："会挤占校内学科吗？" → 高频低压的节奏。"孩子会抗拒这种严谨吗？" → 导师在孩子的水平上迎接他；严谨以"更好的问题"到来，而非压力。"远程导师靠谱吗？" → 具名、有资历、了解孩子声音的引路人，每节课皆有录像。

**反向画像——DODO 不服务谁**（点名它，既保护高端定位，也提升线索质量）：寻求廉价应试、快速作业代劳、纯口语陪练，或被动托管的家庭。DODO 面向想要*深度*、愿意投入可量化多周期历程的家庭。不要为了赢得不匹配的家庭而稀释课程。

## 02 · 三条品牌真理

| 真理 | 怎么用 |
|---|---|
| **1. 认知层面的英语精熟是首要目标。** 精确的思考、基于证据的论证、有意图的写作——这种训练会迁移到孩子使用的每一种语言。 | 每一页都把英语精熟定位为*首要*成果——做标题，而非附注。双语是下游结果。 |
| **2. 精熟是由人教出来的，不是由产品交付的。** 一位具备资质的导师听得出孩子如何推理，追问他*没有*提出的那一点，并指导他为一个观点做口头辩护——这是书本、App 或 AI 都做不到的工作。 | 以真人、一对一的导师关系与**"表达（Speaking）"板块**为先——这是 DODO 的护城河，也是 AI 时代论点（§04a）的种子。让 AI 反驳（§01b）随手可用；绝不假装替代品不存在——去重构它。 |
| **3. 我们把成长写在纸上。** 每个周期都以外部标准来衡量——一个 Lexile 数字、一次 6+1 特质的移动——在第 0、8、16 周。家长在续费前就看见变化。 | 每个转化页都带一个具体数字。把衡量定位为**问责**，而非装饰——杜绝空泛的"效果已验证"。 |

## 03 · 名字——Do + Do

DODO 不是那只鸟。它是 **Do + Do**——在两种语言中、在每一个层级、同时地"去做"。

- **DO（英语）**——学术可能性、正式论证、孩子将要引领的未来的语言。
- **DO（母语）**——情感内核、第一透镜；*正因为*英语严谨，母语得以保留并加深。

双重的 Do 也是对**迭代**的承诺——做，再做，每一轮更深。

## 04 · 我们服务谁

> **2026-08-26 管理层覆盖——按人群 + 意愿定位（取代 2026-05-21 全球定位转向）：** DODO **不再显性面向国际/全球流动家庭**——该维度现为**隐性**（课程服务全球；中英双语站点无需标题即承载它）。定位现为**人群 + 志向导向：任何符合画像、希望把孩子语言艺术打磨到精熟层级的家庭——包括本地、已安定的家庭**，而不仅是迁居或离散家庭。**停用**"全球流动家庭"/"面向全球家庭"/"students around the world"作为标题措辞。国际维度依旧真实且可用——只是不再做标题。

**核心人群**（驱动内容与声音）：重视教育、孩子英语已够用但尚未达精熟的家庭，孩子 **7–15+ 岁**。在北美华裔离散枢纽（多伦多 · 温哥华 · 卡尔加里 · 蒙特利尔 · 美国主要都市）及这些市场的本地家庭中都强——但受众由**志向定义，而非地理或流动性**。本地与国际皆适配。

> **2026-06-01 母语措辞：** 非核心市场正文中，孩子的第一语言称**"母语"**，而非"中文"——刻意面向核心市场的界面除外。双语深度作为下游副产品（源自真理 1，永不做标题）与语言无关。

| 家庭情形 | 真实意愿/恐惧 | DODO 解决什么 |
|---|---|---|
| **本地、已安定**（2026-08-26 新焦点） | "孩子在校没问题——但我要真正的深度，而非只是好成绩。" | 高于校内考察的精熟级阅读与写作 |
| 学术雄心 | SAT / IB / SSAT / 领导力层面的英语 | 七级历程按这些成果校准 |
| 双语家庭 | "我要强英语，又不丢母语。" | 英语精熟为先；双语深度自然浮现（重构，别安抚） |
| 迁居/离散（现为隐性，非标题） | "孩子将来要在任何地方都能学术立足。" | 可随身迁移的学术基础设施 |
| 担忧 AI 时代 | "孩子会拥有 AI 无法替代的能力吗？" | AI 无法替代的判断力（完整反驳见真理 2 · §01b） |

**写作时牢记的家长画像：** 达大学毕业阅读水平（常为双语）。对营销套话高度怀疑，会核查主张。认可他们熟悉的框架（Lexile、Common Core、IB）。时间紧——hero 超过 25 字就不读。

## 04a · 营销方向与指令（2026-08-26 新增）

本指南主要是文案生产手册——但没有方向的内容会漂移。本节是每个界面都应向上对齐的**战略层**。*（原理与完整分析：`docs/_archive/brand-guide-critique-2026-08-26.md`。）*

**1 · 要占据的品类。** 写作要去定义并占据**"精熟层面的英语语言艺术"**这一品类——不是"补习"，不是"英语课"。品类占有者拥有定价权，也更容易被 LLM 引用。每一个方法论/权威界面都应强化品类，而非仅推销产品。

**2 · 招牌论点——AI 时代。** DODO 可占据的市场观点：**AI 无法替代的阅读、推理与写作判断力。** 真理 2 是种子；这是论点。战略界面（首页、/about、/methodology、公关、社媒）都应向它对齐。与 DODO Coding 姊妹品牌互相呼应，而非重复。

**3 · 需要正视的市场力量**（写作时放在视野里）：
- **替代威胁 = 免费 AI 家教。** 永远把 AI 反驳话术（§01b）放在手边；绝不假装替代品不存在——去重构它。
- **买方议价力高；转换成本低。** 留存是*定位*工作，不只是运营：把**长期导师关系**、**七级阶梯（已投入、可见的进度）**与**社群**框定为护城河——而非仅是温度。
- **空白地带。** 尚无占主导的高端英语语言艺术品牌——在别人命名品类之前先占据它。

**4 · 增长杠杆（指令）。**
- **转介引擎。** 75%+ 口碑是飞轮——把它当作*系统*（创始家庭转介闭环），而非证据数字。在紧密社群里是最便宜的获客杠杆。
- **权威 / GEO。** §07a 研究依据是可引用的护城河。作为家长教育内容 + 引流磁铁部署；可量化目标是**被 LLM 引用**（见 §14 与 `docs/workflow.md`）。
- **社群。** 离散与本地家长都在聚集（微信 / 小红书 / 本地网络）。DODO 家长社群既抬高转换成本，又驱动转介。
- **培育本地需求。** 按 2026-08-26 定位调整，主动争取**本地、已安定的家庭**——不只是流动/离散家庭。

**5 · 证据指令。** 高端定价需要比单一锚点案例更深的公开证据。建立一批匿名成果案例 + 视频证言指引；§07a 赢得*方法*可信度，但*成果*证据仍需深度。

**6 · 护栏。** 营销方向服务于品牌真理（§02）与反面词典（§10）。任何增长手段都绝不引入折扣、缺陷、紧迫或补救语言。

## 05 · The Loop——阅读 → 思考 → 表达 → 写作

**永远用这个确切短语。永远这个顺序。正文里永远称作 The Loop——但绝不作为章节标题或体系名（§06 覆盖；具名体系是"语言循环体系"）。**
*（注：The Loop 是每节课的方法论。**LCS**——文学精读 · 系统写作训练 · 表达——是组织跨周期课程的底层教学体系。范畴不同，同属一家。见 §06。）*

| 阶段 | 发生什么 | 课程锚点 |
|---|---|---|
| **阅读** Read | 古典文学 + Lexile 匹配读物。文本刻意设定在当前水平之上 80L–120L。语言不是学科，而是关于品格、后果与技艺的活的论证。 | **MCT** 锚点：*Mud Trilogy*、*Building Language*（拉丁/希腊词根）、*Caesar's English*（词源）、*Music of the Hemispheres*（诗学）。辅以 SAT 必读经典。 |
| **思考** Think | 证据整理、推理链、因果映射、换位思考、发现复杂性。每一个"思考"都指向*某种特定的推理*，绝非通用理解题。 | 每节课部署 **哈佛零点项目（Project Zero）** 的可视化思维（Visible Thinking）routine。routine 名称只存于导师端材料，不进 hero 文案。 |
| **表达** Speak | 口头辩护、立场表达、视角转换——始终扣住所读文本。导师先问一个更好的问题，再给评价。 | 与**母语为英语、受过专业训练、仍在授课的导师（Navigator）**一对一苏格拉底式对话——学位来自世界前 50 强大学，专精英语文学与写作。 |
| **写作** Write | 句 → 段 → 文 → 学术。学生因阅读与思考而写，绝不套模板。以 6+1 特质量规评估。 | **MCT** 写作弧：*Grammar Island → Sentence Island → 段落 → 文章 → 学术写作*。以 **6+1 特质**（Education Northwest）评估：思考、结构、声音、用词、流畅、规范、呈现。 |

**两种课型：**
- **A 型——文学课（Literacy Session）。** 学生朗读并进入文本。导师在句子层面精准辅导——词汇、语调、理解。锚定 **MCT Building Language / Caesar's English** 词汇轨 + 指定小说。
- **B 型——写作课（Writing Session）。** 学生思考、讨论、起草。导师以一个可视化思维 routine 开场，先问更好的问题再评价，以 6+1 特质量规评估产出。

## 06 · 产品架构

## 08 · 声音——语气要柔，底子要深

**人设。** 像 DODO 最好的导师隔着餐桌和家长聊天那样去写：一个真正读过这些书、乐意花一小时讲清楚一个句子为什么好、却绝不让你干坐着听讲的人。学养深厚，对手艺笃定，也真心喜欢孩子、喜欢语言。先温暖。学问藏在细节里，不必自报家门。

**语气柔、底子深——落到文字上：**
- **让句子有呼吸。** 完整的句子，有从句，把一个念头讲完。不是每句都要有"金句"。每六个字就停下来强调一次，读起来像推销；愿意信任读者，读起来才像一个人在说话。
- **学问轻着穿。** 深度靠一个真实而具体的细节显出来——比如孩子第一次拆开一个从没见过的拉丁词根——而不是堆框架、每句塞数字。
- **有关怀，不推销。** 平实而体贴地说出家长真正的期望和担忧，然后讲我们做什么。不施压、不制造恐惧、不倒计时。
- **一点点乐趣。** 语言本就美好，喜欢它没什么不好——一丝好奇、温度或俏皮是恰当的。但别为搞笑而搞笑。

| 维度 | 听起来像 | 不是这样 |
|---|---|---|
| **温暖** | "很多孩子身上有一道成绩单看不见的小缺口——而且往往不是家长担心的那一处。" | "今天就解锁孩子的真正潜能！" |
| **有学养**（深，却轻着穿） | "我们读整本书、不用简写本，因为孩子是靠作家真正写下的句子长大的。" | "我们的专有课程整合了业界领先的方法论。" |
| **从容** | "不必着急。一个周期十六周，成长往往先悄悄地，然后忽然就来了。" | "16 周见效——保证！别再等了。" |
| **安静的自信** | "我们会量给你看，你不必只听我们一面之词。" | "家长最信赖的第一英语课程。" |

**见到即删——我们要离开的那种腔调**（就是那种"油"的、路演式的、AI 味的节奏；在自己的草稿里抓它）：
- **三连排比成瘾。** "读懂复杂、以据论证、有意识地写"。一处排比没问题；一页三处就是毛病。让节奏有变化——有时只说一件事。
- **破折号的鼓点。** 每隔一句就用破折号铺一个落点。破折号留给真正的插叙，少用。
- **反转公式。** "不是 X，而是 Y。""不是口号，是理念。"把它当反射动作戒掉。
- **短句堆叠造气势。** "每一节课。每一周。绝无例外。"
- **绝对化的最高级。** "书本与 App 都替代不了""AI 唯一做不到的""为未来而生"。更安静、更具体，永远胜过更大。
- **正文里冒出落地页腔。** 正文该像一个人在解释，不是 hero 区在喊。
- **拔高重要性。** "多数家长忽略了……""这会改变一切。"把话直接说出来就好。

**改写示例**（同一句，去掉油腻）：
- ✗ "真人一对一，由导师亲授——书本与 App 都替代不了。" → ✓ "每节课都是真人一对一——一位会慢慢懂得你孩子怎么想的导师。"
- ✗ "……并能把这套思考当众辩护出来——AI 替代不了的判断力。" → ✓ "……然后把想法说出来，为自己的看法辩护。这种思维习惯很难教，看着它长出来却很动人。"
- ✗ "每一节课，每一周，坚持高频低压。" → ✓ "每节课都是同样四步——读、想、说，再写。顺序是有讲究的，每周保持不变，孩子才好安顿下来。"

**依然是肯定语气，只是不再用力过猛。** 多用主动、平实的动词——我们教、我们读、我们量、孩子学会。你不必回避"帮助""支持"才显得有力；温暖不是软弱。我们放下的是硬推销的腔调，不是普通的人话。

**"我们不做／我们做"的对比——省着用。** 一个好用的手法，但要节制。仅当：(1) 它化解一个正阻碍家庭的真实误解；(2) 那个"不做"是他们在别处确实经历过的；(3) 那个"做"确实出人意料；(4) 需要品类澄清（我们不是补习中心）。绝不当作节奏上的口头禅。

**ZH 专属声音模式：**

| 模式 | 听起来像 | 为什么 |
|---|---|---|
| **标题先清楚，再带温度** | 用平实的话先点出家长真正的关切；一个一眼就懂的意象是欢迎的——如"老师与导师之间，差的是一张地图。" | 华裔移民家长回应直接——但"温暖而清楚"胜过"生硬而油"。先点破担忧，再像个人一样安抚，而不是推销。"外教"只作对比词（§09）。 |
| **用一个画面开头，别用短打堆叠** | 段首用一句清楚温暖的话，或一个真实的小场景，然后让文字舒展开 | 停掉两句短陈述的鼓点——在中文里它同样是推销节奏。 |
| **中文里避免战斗隐喻** | "表达并支持自己的立场"（非"捍卫立场"）；"更深入的问题"（非"更尖锐的问题"） | 英文里管用的战斗动词，中文家长语域里显得对抗。改用协作/深度动词。 |
| **四字成语式框架** | "高频低压"·"可见可量化" | 把益处+体验压缩成四字箴言式简写，可跨界面复用。 |
| **删掉空洞的"我们保证"尾巴** | 删"而不是猜测"/"每一个主张都有数据支撑"/"我们保证" | 空承诺式尾巴削弱权威；但"量给你看"这样具体的事实不在此列，可以保留。 |
