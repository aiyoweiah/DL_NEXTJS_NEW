- **Claude Skills intercept most GEO prompts** — see §Structural findings #2. Framework/comparison/premium/one-on-one/curriculum phrasings all trigger design or planning skills. Only "Best [x] in [City]" reliably triggers web search on Claude. Anticipate this; skip cells that predictably break.
