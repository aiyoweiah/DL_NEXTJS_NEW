1. **ChatGPT is picking up dodolearning.com for city-specific buyer queries.** The Temporary-Chat A1 capture ranks DODO #1 with lifted-verbatim positioning language (Read → Think → Speak → Write, both age bands, Little DODO, Metro Vancouver). The gap is that this hasn't cross-pollinated to Perplexity, Claude, or Gemini yet, and hasn't reached the framework-specific or comparison queries even on ChatGPT.
2. **The May baseline conclusion still holds for Perplexity + framework queries:** DODO's bottleneck for those surfaces remains the off-site mention graph.
3. **The competitor field is drifting on Perplexity.** The May baseline was dominated by private-listicle-SEO'd names (Reading Town, Gaines, LWL). The August capture is dominated by public-institution names (TPL, MOSAIC, Achieve3000). Private-listicle path is closing at the LLM layer for discovery queries.
4. **Winnable framework path stays winnable but blocked on authored content.** A6 (MCT) confirmed as the biggest miss across both Perplexity + ChatGPT — both answer purely from publisher perspective. `/credentials` page + MCT pillar blog post are the concrete unblock.
5. **Wukong ELA is the head-to-head ZH competitor** on Perplexity ZH; `huaren.us` visible in citation graph.
6. **Personalization contamination is a real measurement risk on ChatGPT.** Any capture from Peter's authenticated account must be in Temporary Chat mode. This applies to Claude and Gemini too if run from Peter's accounts — verify each platform has an equivalent "no memory / no history" mode before capture.
7. **Prompt A5 rewording candidate confirmed** — Perplexity read it as a remediation query. ChatGPT capture would settle it.
