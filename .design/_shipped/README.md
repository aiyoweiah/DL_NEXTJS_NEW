# .design/_shipped

Design proposals that **have been applied to live files**. This folder is
decision history.

**Why it exists:** staged proposals and shipped ones used to sit side by side in
`.design/`, distinguished only by a status line inside each README — and one of
those status lines went stale. `program-family-parallel` still read *"Audit +
proposal in progress. No live files have been edited."* months after it shipped,
which would have led a successor to re-apply live work. The folder now carries
the status, so it cannot drift out of sync with a sentence.
